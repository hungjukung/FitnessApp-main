專案簡介

這個 App 在解決什麼問題？

  • 體重紀錄 — 每日記錄，自動繪製趨勢圖
  • 體態照片 — 拍照對比，視覺化進度
  • AI 分析建議 — 根據數據給出個人化洞察
  • 行事曆檢視 — 快速回顧每天的紀錄
  • 完整帳號系統 — 安全登入、資料雲端同步
🎯

目標族群

想認真管理體態、但不想用複雜 App 的人

✨

核心價值

簡單記錄 + AI 幫你解讀數字背後的意義

資料庫設計

本地 SQLite 資料表

⚖️

weight_logs

每天的體重紀錄，以日期為主鍵，只儲存一筆

📷

photo_logs

體態照片，每天可存多張，支援排序

🤖

ai_insights

AI 模型產生的每日建議文字，記錄使用的 model_id

💡 設計重點：每個使用者有獨立的 SQLite 檔案（fittrack_[userId].db），資料完全隔離。支援 Migration 版本管理，App 升級時自動套用結構變更。

安全設計

認證與授權流程

🪙

Access Token

有效期 1 小時
JWT 格式，每次 API 請求帶入

短效 → 降低洩漏風險

🔄

Refresh Token

有效期 90 天
UUID 格式，存於資料庫

長效 → 使用者不需頻繁登入

🔒

密碼安全

bcrypt 12 rounds 雜湊
永不儲存明文密碼
